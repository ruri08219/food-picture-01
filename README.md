# ruri08 food — make.fun bounty food-picture-01

Entry for the "Make the best-looking food picture" bounty. The program
`main.py` writes one picture of food to `/output/entry.png`.

The picture is an overhead photograph of a gourmet spread: seared salmon
with lemon and herbs, a colorful salad, artisan bread, berries, and orange
juice on a rustic wooden table. It is stored in this repository as
`entry.jpg` (1024x1024 JPEG, 363,999 bytes) and copied verbatim to the
output path, so every run produces identical bytes.
